========================================
REGISTRU TRANSFERURI MEDIA v2.0
Ghid Instalare și Utilizare
========================================

CERINȚE SISTEM:
- Windows 10/11 sau Linux
- Python 3.11 sau mai nou
- 100 MB spațiu liber

INSTALARE RAPIDĂ:
==================

1. Deschide terminal/cmd în acest director

2. Instalează PyQt6:
   Windows:  pip install PyQt6
   Linux:    pip3 install PyQt6

3. Pornește aplicația:
   Windows:  python main.py
   Linux:    python3 main.py

VERIFICARE INSTALARE:
=====================

La prima pornire, aplicația va:
✓ Crea baza de date transferuri.db
✓ Inițializa schema SQL
✓ Adăuga operator admin implicit

Dacă vezi fereastra principală → instalare reușită!

UTILIZARE:
==========

Tab "Înregistrare Nouă":
- Completează formularul cu datele transferului
- Câmpurile obligatorii: instituție sursă, PC, mediu transfer,
  persoană, destinație, clasificare
- Apasă "Salvare" → Nr. registru automat generat

Tab "Statistici":
- Vizualizare total transferuri
- Grupare pe clasificare
- Actualizare automată

PROBLEME FRECVENTE:
===================

Q: "ModuleNotFoundError: No module named 'PyQt6'"
A: Rulează: pip install PyQt6

Q: "Permission denied" la pornire
A: Rulează ca administrator sau verifică permisiuni

Q: Baza de date nu se creează
A: Verifică că ai drepturi de scriere în director

Q: Fereastra nu apare
A: Verifică că Python 3.11+ este instalat: python --version

BACKUP:
=======

Pentru backup:
1. Copiază fișierul transferuri.db
2. Salvează pe mediu extern
3. La restaurare, înlocuiește fișierul
